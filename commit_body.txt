feat(mmal/clock): use buffer flags for frame completeness with pts_delta fallback

Use buffer flags instead of timestamp deltas to determine if a complete frame has been received.

This adds the `flags` field to `MMAL_CLOCK_BUFFER_INFO_T` so that the `MMAL_BUFFER_HEADER_FLAG_FRAME_END` and `MMAL_BUFFER_HEADER_FLAG_FRAME_START` buffer flags can be properly inspected for frame completeness in `clock_update_stream`.

Legacy clients that omit buffer flags are still supported via the fallback `pts_delta` logic.

Addresses the FIXME/XXX comment in `interface/mmal/components/clock.c`.
